# Node.JS + rerank models

## Getting Started

```
git clone https://github.com/liara-cloud/ai-rerank-examples.git
```

```
cd ai-rerank-examples
```

```
git checkout python
```

```
mv .env.example .env # and set ENVs
```

```
pip install -r requirements.txt
```

```
python main.py # and done ... 
```
